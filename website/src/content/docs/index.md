## Browser access

Your browser connects to a running OpenTig instance. Files, Git operations, and installed integrations run on that host. Pair your browser using the link or code provided by OpenTig.

To keep the CLI running after closing your terminal, set up a [background service](/docs/getting-started/#background-services).

# opentig

**A focused workspace for your Git repositories.**

`opentig` is the short name of [`@opentig/cli`](https://www.npmjs.com/package/@opentig/cli), OpenTig's command-line server. It is published at the same version and runs exactly the same command, so these are equivalent:

```bash
npx opentig@latest
npx @opentig/cli@latest
```

Keep OpenTig running in the background, with an `opentig` command on your `PATH`:

```bash
npx opentig@latest service install
```

Requires **Node.js 24+** and **Git 2.31+**. Install only one of `opentig` and `@opentig/cli` globally: both provide the `opentig` command.
